# ระบบตรวจสอบความพร้อมของสินค้าคงเหลือแยกตามสาขา BaanDee

## 1. ภาพรวมโครงงาน

ต้นแบบเว็บไซต์สำหรับตรวจสอบความพร้อมของสินค้าแยกตามสาขา ผู้ใช้สามารถค้นหาและกรองสินค้า ดูจำนวนคงเหลือ ตรวจสอบรายละเอียด บันทึกหมายเหตุ แก้ไขหมายเหตุ และดาวน์โหลดข้อมูลเป็นไฟล์ CSV ได้

นอกจากนี้ ระบบยังเชื่อมต่อกับ API จำลองสำหรับตรวจสอบข้อมูลคำสั่งซื้อ เพื่อสาธิตการเชื่อมต่อระหว่างระบบ

**หมายเหตุ:** ข้อมูลสต็อกทั้งหมดเป็นข้อมูลจำลองเพื่อการศึกษา ไม่ใช่ยอดสต็อกจริงจาก BaanDee

## 2. แหล่งข้อมูล

- ชุดข้อมูลสินค้า: ข้อมูลสินค้าที่ใช้ในโครงงาน
- ข้อมูลสต็อกจำลอง: ข้อมูลจำนวนสินค้าคงเหลือของแต่ละสาขาที่สร้างขึ้นเพื่อสาธิต
- API จำลอง: ใช้ทดสอบการตรวจสอบคำสั่งซื้อ ข้อมูลสินค้า และรายการแจ้งปัญหา
- ข้อมูลทั้งหมดใช้เพื่อการศึกษา และไม่ได้ยืนยันว่าเชื่อมต่อกับระบบจริงของ BaanDee

## 3. เกณฑ์การแสดงสถานะสินค้า

- จำนวนสินค้าคงเหลือเท่ากับ 0: หมดสต็อก
- จำนวนสินค้าคงเหลือมากกว่า 0 แต่ไม่เกินจุดสั่งเติม: ใกล้หมด
- จำนวนสินค้าคงเหลือมากกว่าจุดสั่งเติม: พร้อมจำหน่าย

เกณฑ์เหล่านี้เป็นกฎที่กำหนดขึ้นสำหรับต้นแบบโครงงาน ไม่ใช่นโยบายที่ได้รับการยืนยันจาก BaanDee

## 4. ความสามารถของระบบ

- เลือกสาขาที่ต้องการตรวจสอบ
- ค้นหาและกรองรายการสินค้า
- แสดงจำนวนสินค้าคงเหลือและจุดสั่งเติม
- แสดงเวลาของข้อมูลที่ใช้ตรวจสอบ
- บันทึก แก้ไข และเรียกดูหมายเหตุ
- ดาวน์โหลดผลการค้นหาเป็นไฟล์ CSV
- เชื่อมต่อ API จำลองเพื่อตรวจสอบคำสั่งซื้อ
- แสดงผลเมื่อพบข้อมูล ไม่พบข้อมูล หรือเชื่อมต่อ API ไม่สำเร็จ

## 5. การจัดการคุณภาพข้อมูล

โครงงานแบ่งข้อมูลออกเป็นข้อมูลดิบ ข้อมูลที่สร้างขึ้นเพื่อสาธิต ข้อมูลที่ผ่านการทำความสะอาด และข้อมูลที่ต้องตรวจสอบเพิ่มเติม

รายงานคุณภาพข้อมูลและผลการทดสอบอยู่ในโฟลเดอร์ `data/reports/`

## 6. โครงสร้างโครงการ

- `src/app.py` — โปรแกรมเว็บไซต์ที่พัฒนาด้วย Streamlit
- `api/` — โปรแกรม API จำลอง
- `data/raw/` — ข้อมูลต้นฉบับ
- `data/generated/` — ข้อมูลจำลองสำหรับสาธิต
- `data/cleaned/` — ข้อมูลที่ผ่านการทำความสะอาดและรวมข้อมูลแล้ว
- `data/quarantine/` — ข้อมูลที่ต้องตรวจสอบเพิ่มเติม
- `data/reports/` — รายงานคุณภาพข้อมูลและผลการทดสอบ
- `tests/` — โปรแกรมและสคริปต์สำหรับทดสอบระบบ

## 7. วิธีติดตั้งและเรียกใช้งาน

### 7.1 ติดตั้งไลบรารีที่จำเป็น

เปิดเทอร์มินัลในโฟลเดอร์หลักของโครงการ แล้วรันคำสั่ง

```bash
pip install -r requirements.txt
```

### 7.2 เปิดใช้งานเว็บไซต์

รันคำสั่งต่อไปนี้จากโฟลเดอร์หลักของโครงการ

```bash
streamlit run src/app.py
```

### 7.3 ตั้งค่าการเชื่อมต่อ API

กำหนดตัวแปร `BAANDEE_API_URL` ให้ตรงกับที่อยู่ของ API จำลองที่นำไปเผยแพร่แล้ว โดยดูตัวอย่างการตั้งค่าได้จากไฟล์ `.env.example`

หากใช้งานผ่าน Streamlit Community Cloud ให้กำหนดตัวแปรนี้ในส่วน Secrets ของแอปพลิเคชัน

สามารถตรวจสอบสถานะของ API ได้ที่เส้นทาง `/health`

เว็บไซต์และ API จำลองเป็นบริการแยกจากกัน

## 8. ผลการทดสอบ

ดูรายละเอียดได้จากไฟล์ `data/reports/test_results.csv`

- T01–T05 เป็นการทดสอบอัตโนมัติ
- T06–T08 เป็นการทดสอบด้วยตนเอง ซึ่งผู้พัฒนาเป็นผู้รายงานผล

ควรเก็บภาพหน้าจอหรือหลักฐานประกอบผลการทดสอบด้วย หากข้อกำหนดของรายวิชาระบุให้ส่งหลักฐาน

## 9. ข้อจำกัดของระบบ

- ข้อมูลสต็อกเป็นข้อมูลจำลอง ไม่ใช่ยอดสินค้าคงเหลือจริงของ BaanDee
- การเชื่อมต่อภายนอกใช้ API จำลองสำหรับการศึกษา ไม่ใช่ API อย่างเป็นทางการของ BaanDee
- หมายเหตุจัดเก็บในไฟล์ CSV ภายในระบบ ไม่ใช่ฐานข้อมูลสำหรับใช้งานจริง
- เวลาที่แสดงอ้างอิงจากเวลาที่บันทึกไว้ในชุดข้อมูล จึงอาจไม่ใช่เวลาปัจจุบัน
- การตรวจสอบคำสั่งซื้อผ่าน API ขึ้นอยู่กับความพร้อมใช้งานของบริการ API จำลอง
